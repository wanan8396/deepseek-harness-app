# 分享与草稿

从其他 Android 应用分享文字、链接、图片或文件到 DeepSeek harness 时，接收内容是待检查的草稿，不会因接收分享就自动发送给模型。

## 接收后发送

1. 在来源应用的系统分享面板选择 DeepSeek harness。
2. 回到 App，确认当前连接是本机，并等待官方网页可用。
3. 检查输入框中的文字、目标对话和已出现的附件，补充自己的问题。
4. 由你点发送后，内容才作为消息交给当前引擎处理。

电脑网页与手机本机的草稿处理相互隔离。本机收到的分享不会自动发送到电脑，也不会自动替电脑选择同名对话。想在电脑网页使用内容时，先确认目标，再手动粘贴或使用该网页自己的附件入口。

## 文字或附件没有进入输入框

网页需要先就绪，且要支持对应草稿操作。文字写入失败时，App 会提示已复制，可在确认目标后手动粘贴；附件失败或过大时按提示缩小范围或重新选择。当前手机草稿桥接一次最多处理合计 16 MiB 的附件，这与模型服务的附件上限不是同一限制。

看到分享完成或 App 被打开，不代表附件已加入。附件读取失败不会凭空补回文件内容，发送前逐个检查。

## 复制与向外分享

对话里的复制、导出或分享使用当前官方网页实际提供的操作；不同电脑版本和已启用插件会影响可见入口。当前手机壳不另提供旧版云端分享链接管理、加密回放文件或图片模板面板。

对外发送前人工检查正文、附件、文件路径及链接中是否包含 API Key、token、cookie 或个人资料。撤回草稿或删除原对话不会收回别人已经保存的副本。不要把登录网页的链接当成可公开的对话分享链接。

打开或整理对话见 [对话](01-chat.md)，连接目标的区别见 [本机与电脑网页](05-web.md)。
