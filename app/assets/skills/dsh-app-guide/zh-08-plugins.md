# 官方网页插件

DeepSeek harness 手机壳显示官方网页，插件在当前引擎中运行。这里使用普通官方 Web 插件体系，不依赖旧手机专用原生 SDK、桥接面板或原生插件市场。

## 找到插件

点鲸鱼打开侧栏，在网页提供的插件入口查看插件。官方设置里的内置插件和动态插件页面作用不同：前者管理随引擎的组件配置，后者按当前页面提供的安装与管理能力操作。

1. 先确认当前连接是本机还是电脑。
2. 阅读插件的来源、版本要求与说明，再使用网页提供的安装或启用操作。
3. 插件提供设置时，在其网页设置中填写；页面要求保存时完成保存。
4. 只有网页明确要求重载或重启时再按提示处理，重启可能打断该引擎上正在运行的任务。

电脑上的安装改变电脑的环境，不会把同一插件装到手机。普通升级保留用户 profile 不代表每个第三方插件都与新运行时兼容。

## 没有出现或操作失败

- 检查插件是否安装到当前引擎、是否启用以及版本是否兼容。
- 阅读页面的错误与重启提示；先保留失败状态，不假设再次点击就已成功。
- 官方页面没有某个设置或入口时，不去寻找旧原生 SDK 的按钮、状态条或消息菜单。
- 安装脚本、工具与模型调用在目标引擎执行，插件可能接触该引擎可用的文件或外部服务；填写服务凭据时使用其指定字段。

## 停用与卸载

停用、卸载和删除插件数据是不同动作。阅读当前网页确认框，核对是否需要重启以及哪些设置或数据会保留，不套用旧客户端的卸载顺序和撤销时间。

本说明不保证所有官方目录项或第三方插件都适合 Android 环境。涉及本机启动与兼容升级见 [本机环境](03-engine-hosts.md)，官方任务功能见 [自动化任务](12-automation.md)。
