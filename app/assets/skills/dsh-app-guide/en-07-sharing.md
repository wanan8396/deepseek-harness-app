# Sharing and drafts

Text, links, images and files shared from another Android app to DeepSeek harness are pending draft content. Receiving a share does not automatically send it to a model.

## Review and send

1. Choose DeepSeek harness in the source app's Android share sheet.
2. Return to the app, confirm that the destination is This phone, and wait for the official webpage to become available.
3. Review the composer text, target conversation and attachments that actually appeared, then add your request.
4. Only your Send action submits the content as a message to the current engine.

Computer webpages and phone-local draft handling are isolated. An incoming local share does not automatically go to a computer or select a computer conversation with the same name. To use it there, verify the destination before pasting or adding attachments through that webpage.

## Missing text or attachments

The webpage must be ready and support the draft action. If inserting text fails, the app reports that it was copied; paste manually after checking the target. For failed or oversized attachments, reduce the selection or choose again as prompted. The current phone draft bridge processes at most 16 MiB of attachments per handoff; this is separate from the model service's limit.

A completed share action or an opened app does not establish that an attachment was inserted. A failed file read does not supply missing content; inspect each attachment before sending.

## Copying and sharing outward

Use copy, export or share actions actually supplied by the current official webpage. Computer versions and enabled plugins may expose different entries. The current shell does not add the old cloud-share manager, encrypted replay format or image-template panel.

Before sending anything outward, inspect text, attachments, paths and links for API keys, tokens, cookies or personal information. Removing a draft or original conversation does not retrieve copies already saved by recipients. A login-page link is not a public conversation share link.

See [Conversations](01-chat.md) for navigation and organization, and [Phone and computer webpages](05-web.md) for destination differences.
