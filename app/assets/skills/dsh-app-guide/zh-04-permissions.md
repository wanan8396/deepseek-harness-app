# 系统权限

DeepSeek harness 手机壳的权限页用于文件、通知与后台运行。普通模式启动本机引擎时自动检测 Root，此页没有手动控件；恢复模式跳过 Root 探测并使用 PRoot。

## 打开权限页

点底部右侧的本机/连接电脑入口，在本机一行点权限图标，进入本机系统权限。首次引导也会显示系统权限页。按需点具体项目后才进入 Android 系统页面；从系统返回后会重新读取可检测状态。

## 文件

允许存储访问后，本机引擎能够使用已开放的手机文件范围；这不等于所有应用的私有数据都可读。授予前先考虑工作任务是否需要相册、下载和文档，模型工具在权限允许的范围内也可能修改文件。

网页附件选择与把整个手机存储开放给引擎是不同操作。只想发送某个文件时，先使用网页提供的附件入口，核实草稿后再发送。

## 通知与后台

- 允许通知，便于看到运行状态及当前产品实际提供的提醒。通知被系统关闭时，网页仍可能在前台正常工作。
- 允许后台运行、按需关闭电池优化，并检查厂商的后台或自启动选项。
- 部分厂商开关只能由你在系统里查看并确认，App 显示已查看或已确认，不代表系统保证进程常驻。
- 系统强制停止、内存压力和省电策略仍可能结束引擎；重新打开 App 后检查页面并按需重试。

## 自动检测 Root

普通模式每次启动本机引擎时检测一次真实 Android Root；取得 UID 0 且运行条件满足时自动使用 Root，否则使用 PRoot。恢复模式跳过 Root 探测，使用 PRoot。Root 管理器可能在首次检测时显示授权请求；系统权限页没有 Root 的授权、断开或重新检测按钮。

运行中不会热切换方式，打开权限页或切回 App 也不会重新发起 Root 探测。下次普通模式启动时重新检测，数据保留范围见 [本机环境](03-engine-hosts.md)。

## 扫码相机

电脑连接的相机权限只在你主动打开扫码时使用，用于读取二维码地址；手动填写 HTTP/HTTPS 地址不依赖相机。扫码后仍先预览、确认，再进入网页，见 [网页连接](05-web.md)。
