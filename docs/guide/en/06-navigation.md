# Persistent controls and sidebar

The bottom whale opens conversations and workspaces in the DeepSeek harness phone shell.

## The two bottom controls

- Left whale: opens or closes the current webpage's conversations and workspaces sidebar. It may be temporarily inactive before the page is ready or after a loading error.
- Right This phone/Connect computer: selects the destination and opens local permissions and computer address management; see [Settings](10-settings.md).

These belong to the phone shell. Accounts, plugins, models and three-dot menus still belong to the official webpage, not a hidden old native menu.

## Keyboard and overlays

The bottom controls temporarily hide while the keyboard is open, leaving space for the composer and input method. Dismiss the keyboard to use the whale again; there is no need to revoke permissions or clear data to find it.

Opening the sidebar itself does not remove the whale. A blocking dialog or overlay may temporarily hide the bottom controls; closing it restores them. Narrow and landscape screens have different space, so some pages require scrolling.

## Use the sidebar

1. Tap the whale to expand conversations and workspaces.
2. Select a conversation or the new-conversation action, and check the current title.
3. Organize entries through their own three-dot menus, or touch and hold where supported; see [Conversation menus](01-chat.md).
4. Close the current layer through its page control, backdrop or system Back. Back generally handles the open menu, sidebar or webpage navigation first; follow the current page's result.

## Swipe the sidebar and go back

With the phone webpage layout enabled, swipe horizontally with one finger on ordinary content in a narrow window:

- Swipe right by roughly a thumb's width on the conversation to open conversations and workspaces; swipe left while the sidebar is open to close it.
- Swipe right in settings overlays, plugin details, automations or the fullscreen files panel to take the page's existing Back action. Menus and overlays close first, one layer per gesture.
- On phone-shell pages such as local settings, permissions and computer connections, swipe right from just inside the left edge. A short drag settles back. System edge Back remains available.
- Vertical scrolling, diagonal drags, long-press selection, pinch zoom, text inputs, terminals, editors and horizontally scrolling code or tables retain their gestures. Start outside those surfaces to navigate.

The whale, page Back controls and system Back remain available. Wide desktop layouts retain their existing behavior; webpage swipes follow the page's available Back controls.

## If a control does not return

Dismiss the keyboard, close the active overlay and wait for loading to finish. If it remains obscured, record orientation, screen size, menu type and reproduction steps. A webpage overlay issue is not evidence of damaged engine data. See [Troubleshooting](11-faq.md).
