# Conversations

Home in DeepSeek harness is the official webpage. Conversations, workspaces, messages and tool execution belong to the connected engine: the phone runtime in local mode, or the selected computer in computer mode.

## Create and select

1. Wait for the startup cover to finish, then tap the bottom whale to open the conversations and workspaces sidebar.
2. Use the sidebar's new-conversation button, choose a workspace or directory offered by the page, and enter your request. Its label can vary with the official webpage language; this guide calls it a new conversation.
3. Review the composer, model and attachments, then tap Send. Opening a blank page is separate from sending a message.
4. To return to existing work, select its conversation in the sidebar. Use the webpage's search, grouping or scrolling for longer lists.

The computer and phone have separate lists. Switching the connection does not copy records between engines; see [Phone and computer webpages](05-web.md).

## Input and work in progress

- Choose models with the webpage's own model control. If none is available, complete [sign-in and model setup](02-models.md).
- Add files and images through the current webpage's attachment entry. Formats, capacity and image support depend on the webpage and model. Confirm that attachments are present in the draft before sending.
- While the AI works, stopping, additional instructions, questions and tool confirmations are handled inside the webpage. Read the command, files and choices on the current card instead of applying old native-client behavior.
- Line breaks and sending with a phone keyboard follow the current webpage and input method. Old client shortcut conventions are not a guarantee.

## Three-dot and long-press menus

The three-dot button beside a sidebar entry opens that entry's official menu. Where touch-and-hold opens a context menu, its target is still the entry you held. If holding only selects text, use the three-dot button. Check the title and workspace before choosing an action.

- Archiving a conversation organizes or hides the record; it is not permanent deletion. Unarchive an archived conversation before opening it. Work in progress may be stopped; follow the webpage's notice.
- The current ordinary official conversation menu offers archive and unarchive, not the old phone bridge's permanent-deletion flow or its four-second undo promise.
- Deleting a workspace removes its listing only. Its directory and conversation records remain, and the conversations move to Ungrouped. This does not empty the disk directory.
- If a different computer version provides another deletion action, read that confirmation before proceeding. Deleting records, removing workspace listings and deleting files are different actions; do not assume an undo exists.

After a disconnected or unconfirmed operation, refresh the list to verify the result before repeating it. For the keyboard and sidebar controls, see [Persistent controls](06-navigation.md).
