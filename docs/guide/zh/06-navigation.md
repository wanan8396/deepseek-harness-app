# 常驻入口与侧栏

底部鲸鱼是 DeepSeek harness 手机壳的对话与工作区入口。

## 底部两个入口

- 左侧鲸鱼：打开或收起当前网页的对话与工作区侧栏。网页尚未加载好或出现加载错误时，入口可能暂时不可点。
- 右侧本机/连接电脑：选择运行位置，并进入本机权限与电脑地址管理，详见 [设置](10-settings.md)。

两者属于手机壳。网页自己的账号、插件、模型和三点菜单仍由官方网页管理，不藏在另一套旧原生菜单里。

## 键盘与弹层

输入法打开时底部入口临时隐藏，给输入框和键盘留空间。收起输入法后再使用鲸鱼；不要为了找入口而撤销系统权限或清除数据。

打开侧栏本身不会移除底部鲸鱼。真正阻塞操作的对话框或浮层显示时，底部入口可能临时隐藏，关闭浮层后恢复。窄屏和横屏的可用空间不同，页面可能需要滚动。

## 使用侧栏

1. 点鲸鱼，展开对话与工作区列表。
2. 点一条对话或新建入口，检查当前标题。
3. 整理条目时用条目自己的三点菜单；支持时也可长按，见 [对话菜单](01-chat.md)。
4. 用网页的关闭动作、点遮罩或系统返回收起当前层。系统返回通常先处理正在打开的菜单、侧栏或网页导航，结果以当前页面为准。

## 滑动侧栏与返回

启用手机版网页布局后，在窄屏网页的普通内容区域单指横向滑动：

- 对话页向右滑动约一个拇指宽度，展开对话与工作区侧栏；侧栏打开时向左滑动收起。
- 设置弹层、插件详情、自动化任务或全屏文件面板中向右滑动，执行当前页面的上一级返回。已有菜单或弹层优先关闭，一次处理一层。
- 本机设置、系统权限、电脑连接等手机壳子页，从左边缘稍靠内的位置向右滑动返回；短滑松手会回到原页。系统边缘返回仍可使用。
- 竖向滚动、斜滑、长按选字、双指缩放，以及输入框、终端、编辑器和可横向滚动的代码或表格保留原操作。可从其外侧的普通区域开始滑动。

小鲸鱼、页面返回按钮和系统返回继续可用。宽屏桌面布局保持原操作；网页滑动依照页面已有的返回入口逐层处理。

## 入口没有恢复

先收起键盘、关闭当前弹层，再等网页完成加载。仍有遮挡时记录手机方向、屏幕尺寸、菜单类型与复现步骤；不要把网页浮层问题当作引擎数据损坏。具体排查见 [常见问题](11-faq.md)。
