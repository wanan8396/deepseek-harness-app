# 常见问题

## 一直显示启动动图

先确认底部运行位置。选本机时，首次安装、引擎启动与网页加载是不同阶段；正常等待使用循环封面，没有百分比进度。错误页出现后点重试，失败不会靠无限自动重启解决。缺少环境时按页面安装，不先清除数据。

选电脑时，检查电脑服务正在运行、地址和网络可达。手机的本机引擎状态不代表电脑服务状态。网页要求 PIN 或登录时，在网页内完成，见 [网页连接](05-web.md)。

## 发不出消息或模型报错

检查当前目标、网页连接、登录状态和选中的 provider/模型。网页启动 token 与模型 API Key 不同；登录链接过期时重新获取，不把 token 或 cookie 发到对话。保存配置不等于服务商权限和余额已经验证，见 [登录与模型](02-models.md)。

## 切到后台后停止或提醒未到

在本机权限页检查通知、后台运行、电池优化与厂商自启动设置。厂商选项的已确认只是人工核对状态，不保证进程永远保活。系统强制停止后重新打开 App；内存与省电策略仍可能结束任务。

电脑网页模式不把电脑任务变成本机任务，也不自动提供本机那套通知。回到前台后先确认网页是否重新连接，再查看结果。

## 鲸鱼或右侧入口不见了

先收起输入法，关闭正在阻塞的对话框或浮层。键盘与阻塞弹层期间底部入口会临时隐藏；侧栏本身不应把鲸鱼移除。网页未就绪时鲸鱼可能不可点。见 [常驻入口](06-navigation.md)。

## 三点菜单被遮住或长按只选文字

点条目旁的三点，不必依赖长按；确认菜单属于正确条目。小屏、横屏和系统大字体可能改变可用空间，先滚动侧栏或关闭其他弹层。仍有裁剪时记录屏幕方向、字体缩放、具体菜单和复现步骤。

## 手册与菜单不一样

检查是手机壳连接页，还是官方网页设置；再对照本机/电脑及运行时版本。自动化任务使用当前引擎的官方任务页。

## 反馈时提供什么

提供适用运行时版本、Android 版本、Root/PRoot 实际方式或电脑网页模式、操作步骤及可见错误。截图和文字先检查，去掉完整 API Key、token、cookie、登录链接与个人主机地址。不要求导出用户 HOME，也不要把诊断或对话导出当作完整备份。

普通升级与重置的区别见 [本机环境](03-engine-hosts.md)，归档与工作区删除的影响见 [对话](01-chat.md)。
