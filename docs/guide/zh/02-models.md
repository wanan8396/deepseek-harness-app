# 登录与模型

账号、模型和 providers 使用官方网页设置管理。手机壳没有独立的模型渠道编辑器，也不把旧原生设置中的密钥自动补写到当前官方 profile。

## 登录 DeepSeek

1. 打开侧栏，在账号菜单或设置中进入账号与余额。
2. 选择登录，按官方页面提示在浏览器完成登录；页面未自动打开时，使用页面提供的复制登录链接入口。
3. 返回 DeepSeek harness，等待网页显示已登录。过期或失败时重新发起登录，不反复重用旧链接。
4. 需要退出时阅读确认框：退出不等于删除项目和文件，但可能中断使用该账号的任务。

## 添加或选择模型

1. 在官方设置中打开模型页。
2. 选择已有 provider，或使用页面提供的添加入口；按服务商文档填写协议、Base URL、模型 ID 与 API Key。
3. 页面要求保存时完成保存，再回到对话的模型选择控件检查模型是否可用。
4. 上下文、输出长度、图片输入和思考档位只按服务与当前页面实际支持的能力填写，不把名称显示成功当成调用验证成功。

本机与电脑的 provider 配置互相独立。切到电脑后，修改的是那台电脑当前 profile 的配置，不是手机原先的模型列表。

## 分清 API Key、token 与 cookie

- API Key 是模型服务的凭据，填在官方模型或账号页面指定的密钥字段里。
- 网页启动 token 用于进入指定引擎的网页，不是模型 API Key；带 token 的登录链接也属于凭据。
- cookie 是网页登录状态，浏览器和 WebView 可能各有自己的状态。外部浏览器已登录，不代表 App 内网页也已登录。
- 这些内容都不需要粘到对话、截图、日志或反馈材料里。本说明不展示示例密钥、完整 token 或 cookie。

模型报错时先检查当前连接、登录状态、provider 地址和服务商模型权限。页面保存成功不保证余额、网络和模型权限均正常。电脑网页的 PIN 或登录步骤见 [网页连接](05-web.md)。
